# SkillSwapper

An Android app for swapping skills instead of paying for them. Built in Kotlin for Mobile Application Development 1 at SETU.

## Features

- Add, edit and delete swaps (skill wanted, skill offered, location)
- My Lists screen with search
- Bottom navigation bar
- Dark mode, saved in Settings
- Blue, turquoise and purple theme

## Running the app

1. Clone the repo and open it in Android Studio.
2. Let Gradle sync.
3. Run on an emulator or Android phone (API 24+).
